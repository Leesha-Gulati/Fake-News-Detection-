# 📰 Fake News Detection using Machine Learning

## 📌 Project Objective
The objective of this project is to build a machine learning model that can accurately classify news articles as **real** or **fake** using Natural Language Processing (NLP) techniques.

## 📊 Dataset Used
- [Fake News Detection Dataset – Kaggle](https://www.kaggle.com/datasets/subho117/fake-news-detection-using-machine-learning)
- The dataset contains news articles labeled as *fake* or *real* based on factual authenticity.

## 🧰 Tools & Technologies
- **Programming Language**: Python
- **Libraries**: Pandas, NumPy, scikit-learn, NLTK
- **NLP Techniques**: TF-IDF, text preprocessing (tokenization, stopword removal)
- **Modeling**: Logistic Regression, Random Forest, Support Vector Machine (SVM)
- **Deployment (Optional)**: Flask

## 🔍 Steps Followed
1. **Data Loading and Cleaning** – Removing null values, duplicate entries.
2. **Text Preprocessing** – Lowercasing, punctuation removal, tokenization, stopword filtering.
3. **Feature Extraction** – Converting text to numerical form using **TF-IDF Vectorization**.
4. **Model Training** – Training classifiers like Logistic Regression and Random Forest on the extracted features.
5. **Model Evaluation** – Measuring performance using accuracy, precision, recall, and confusion matrix.
6. **Report Generation** – Summarizing the workflow, findings, and future improvements.

## ✅ Results
- **Achieved Accuracy**: ~94% using Logistic Regression.
- **Best-performing Model**: Logistic Regression with TF-IDF features.

## 🔧 What I Would Improve
- Experiment with deep learning models such as **BERT** or **LSTM** for better contextual understanding.
- Apply **cross-validation** to avoid overfitting and improve generalization.
- Build an interactive web application using **Flask** (backend) and **React** (frontend).
